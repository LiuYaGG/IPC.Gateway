# 本机多协议 PLC 压测

四个刷新器各自在独立进程中运行，目标周期为 500 毫秒。点表中的正常点使用确定性的变化值，可以按地址和轮次核对。所有写入目标都是本机模拟器。已有网关标签如果使用同一个模拟器地址，也会看到新值。

| 网关压测设备 | 本机端口 | 正常点 | 坏点 |
| --- | --- | ---: | --- |
| 三菱 D 区，PortDock MC 3E 二进制 | TCP 5000 | D0 至 D1999，2000 点 | S0 至 S9，在本机 PortDock 返回 C05B |
| Modbus TCP，站号 1 | TCP 5020 | HR0 至 HR999，1000 点 | HR1100 至 HR1109 |
| Modbus UDP，站号 1 | UDP 5021 | HR0 至 HR999，1000 点 | HR1100 至 HR1109 |
| AB Logix，槽位 0，路径 1,0 | TCP 44818 | 1000 个独立逻辑点 | PT_MISSING_0 至 PT_MISSING_9 |

Modbus 标签名称保留 40000 至 40999，网关地址使用实际的零基保持寄存器偏移。每台设备的直属标签和四个分组各带两个坏点，名称以“坏点_”开头。三菱每部分有 400 个正常点，另外三个设备每部分各有 200 个正常点。压测点设置为只读，关闭逐点 MQTT 发布。

## 日常启动与停止

1. 启动已有的 PortDock 三菱实例和 PyModbus TCP 实例。UDP 由刷新脚本启动，请先关闭占用 5021 或 8082 的旧 UDP 模拟器。44818 留给压测 AB 实例。
2. 在 VS Code 中打开本目录，选择安装了 PyModbus 和其模拟器依赖的 Python 环境。AB 刷新器需要与本机 64 位 plctag.dll 匹配的 Python。
3. 打开“启动全部刷新.py”，点击右上角的“运行 Python 文件”。四个刷新器在后台工作。启动窗口会打印进程号和本轮日志目录。
4. 首次配置网关时运行“导入压测设备.py”，在本机弹框输入有设备管理权限的账号和密码。已导入的设备直接回读核对。测试过程中可以反复停止和启动刷新器，点表会保留。
5. 在设备管理中打开名称以“压测_”开头的通道，分别查看设备直属标签和分组。可按“坏点_”筛选故障，也可以观察坏点前后的健康点的刷新时间和当前值。
6. 结束时运行“停止全部刷新.py”。本轮拥有的 UDP 和 AB 模拟器随刷新器退出，原来的 PortDock 和 Modbus TCP 模拟器继续运行。需要恢复普通 UDP 模拟器时，可再运行原有的“启动UDP模拟器.cmd”。

## 单独运行一个协议

| 脚本 | 运行效果 |
| --- | --- |
| 刷新三菱D区.py | 对运行中的 PortDock 分块写入 D0 至 D1999 |
| 刷新ModbusTCP.py | 使用功能码 16 对运行中的 PyModbus TCP 分块写入 |
| 刷新ModbusUDP.py | 读取原有 PyModbus 配置，在 UDP 模拟器进程内更新同一组保持寄存器，继续提供 8082 管理页 |
| 启动AB模拟并刷新.py | 启动 ab_server，用 libplctag 分块赋值，在本机 44818 为网关提供标准身份查询和会话注册 |

单独运行时在所在终端按 Ctrl+C 停止。UDP 配置文件默认为 `D:\虚拟modbus\模拟器配置.json`，AB 工具目录为 `D:\libplctag_2.7.2_windows_x64_tools`。迁移时可分别使用脚本参数 `--config` 和 `--tools`。网关导入地址默认为 `http://127.0.0.1:5184`。

## 如何理解测试结果

- AB 使用 BOOL、SINT、INT、DINT、LINT、REAL、LREAL、STRING，每类各 125 个点。ab_server 2.7.2 限制命令行标签声明数，这里用八个底层数组符号承载 1000 个逻辑点。前七种类型包含标量和互不重叠的四元素数组。字符串采用 Logix STRING 布局。
- AB 网关端口只监听 127.0.0.1。底层 ab_server 使用单独的动态 TCP 端口；此版本工具自身监听所有网卡。网关仍从 ab_server 读取实际数据。内置的本机适配只处理身份查询与会话注册，标签读取和错误响应原样返回。
- 本机 ab_server 对这十个不存在的标签返回 CIP 状态 0x03。测试时观察设备级状态和正常点是否一起变为未连接，可以验证坏点隔离是否生效。
- 500 毫秒是模拟器改值节拍。网关扫描、坏点探测、前端推送有各自的周期。布尔值每轮翻转，若两次界面采样正好间隔偶数个刷新周期，显示值可能相同。判断刷新情况时可同时观察整数计数和采集时间。
