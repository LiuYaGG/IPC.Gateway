# 报警记录查询与导出

在“历史库 → 报警记录”中设置条件，再点击“查询”。页面不自动刷新，没有刷新按钮；切换页面后保留已有条件和结果。修改筛选条件会清空旧结果，需再次点击查询。

## 查询条件

- 开始时间、结束时间默认最近 24 小时，按浏览器所在地区的当地时间输入和展示；可以清空其中一项或两项。
- 通道、设备、分组、标签支持展开下拉框后输入名称筛选。更换上级选择时清空下级选择。
- 未选择的条件表示不限制；选择设备后可直接筛选该设备的标签，不必选择分组。
- “直属标签”用于筛选设备下未分组的点位。
- 下拉候选包含当前配置及已保存报警中的对象，历史上已删除的设备或标签仍可以查询。
- 查询后可以翻页和调整每页条数。新增报警不会插入已经打开的查询结果；再次点击查询后才加载新的记录。

## 导出当前页

报警记录和点位历史均提供“导出本页”，只导出当前查询结果所在页。点击后先打开浏览器原生“另存为”窗口，选择保存目录并修改文件名，再保存 `.xlsx` 文件。取消另存为不会请求导出数据。

Excel 记录时间按浏览器时区转换，表头标明时区，文件名中的日期和时间也采用当地时间。国际化语言控制列名与状态；设备名称、标签名称和用户定义消息保留原文。内部存储及接口传输仍保留标准时间信息，避免跨时区查询发生偏移。

路径选择需要支持 File System Access 的 Chrome 或 Edge，并通过 HTTPS 或本机 `localhost` / `127.0.0.1` 访问。普通局域网 IP 的 HTTP 页面可能无法使用系统“另存为”；页面会给出提示，不会自动保存到未选择的目录。

## 权限与保护

- 查询需要“历史库”查看权限。
- 导出同时需要 `history.export`（界面显示“导出历史记录”）。原有该权限继续有效，适用于点位历史和报警记录。
- 查询和导出具有并发限制、取消及超时保护；导出使用与当前页一致的筛选条件、分页和新增报警边界。
- 不会改变报警记录的采集、存储和 MQTT 发布策略。
