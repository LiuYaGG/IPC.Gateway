# 欧姆龙 FINS 数据格式配置

## 界面操作

在“设备管理”中新建或编辑欧姆龙 FINS 设备，在连接参数的“欧姆龙控制器”区域找到“数据格式”，选择与 PLC 数据布局一致的格式后保存。TCP、UDP 使用相同设置。

该设置作用于数值和数值数组，覆盖同步/异步单读、连续批读、离散批读和写入。数组按每个元素独立转换；数据分段传输不会改变元素内部的排列。

## 四种排列

以 32 位数值 `0x11223344` 为例，按低地址到高地址观察 FINS 返回的数据字节：

| 数据格式 | 字节排列 | 说明 |
| --- | --- | --- |
| ABCD | `11 22 33 44` | 高字在前，字内高字节在前 |
| BADC | `22 11 44 33` | 高字在前，字内交换字节 |
| CDAB | `33 44 11 22` | 低字在前，字内高字节在前 |
| DCBA | `44 33 22 11` | 低字在前，字内交换字节 |

常见欧姆龙程序把一个 32 位数的低字放在较低的 D 地址，通常对应 CDAB；实际选择应以 PLC 程序、设备文档和已知测试值为准。

对 16 位数值，ABCD/CDAB 对应 `AB`，BADC/DCBA 对应 `BA`。对 64 位数值，本驱动定义如下：

| 数据格式 | 八字节排列 |
| --- | --- |
| ABCD | `ABCDEFGH` |
| BADC | `BADCFEHG` |
| CDAB | `GHEFCDAB` |
| DCBA | `HGFEDCBA` |

Bool 的物理位号、BoolArray 和字符串沿用各自的编码规则，不参与数值排列转换。

## 旧设备兼容

配置保存在设备连接参数 `driverOptionsJson` 的 `finsDataFormat` 属性中，可选值为 `ABCD`、`BADC`、`CDAB`、`DCBA`。显式设置的数据格式优先于旧的 `wordOrder`。

未设置 `finsDataFormat` 的既有设备按旧配置转换：

| 原字序配置 | 对应数据格式 |
| --- | --- |
| HighWordFirst | ABCD |
| LowWordFirst | CDAB |

打开既有设备进行编辑时也遵循此映射。新设备保持原有缺省行为，默认 ABCD；需要低字在前时选择 CDAB。

界面仅提供一个“数据格式”选择框，避免与旧“字序”同时显示。项目文件和数据库仍通过现有 Protobuf 项目配置保存连接选项，不增加项目字段或数据库迁移。

## 验证范围

使用独立的本地 TCP/UDP 测试端点验证，不访问业务 PLC。覆盖四种格式、16/32/64 位整数和浮点数、数值数组逐元素转换、数组偏移、跨字边界的分段传输、连续/离散批读、坏点拆分、Bool 位号、定长字符串回归、旧配置映射及 Protobuf 保存。
