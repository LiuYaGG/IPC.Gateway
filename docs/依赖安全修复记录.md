# 依赖安全修复记录

检查日期：2026 年 11 月 9 日。范围包括正式前端、后端全部 10 个项目，以及它们的间接依赖。

## 修复内容

修复前 npm 审计报告为 10 项漏洞（7 项高危、3 项中危）；NuGet 在多个项目中检出同一项 MySqlConnector 中危漏洞。

| 依赖 | 修复前 | 修复后 | 说明 |
| --- | --- | --- | --- |
| Vue 及配套编译器、运行时 | 3.5.38 | 3.5.45 | 修复服务端渲染属性名校验中的 XSS 漏洞；所有 Vue 配套包保持一致版本 |
| Vite | 6.4.3 | 6.4.5 | 修复开发服务器、编辑器调用及文件访问相关漏洞，保留 Vite 6 |
| vue-tsc | 2.2.12 | 3.3.14 | 升级类型检查工具；新依赖树不再包含有漏洞的 minimatch、brace-expansion |
| nanoid | 3.3.12 | 3.3.20 | 更新兼容范围内的间接依赖，修复异常参数导致的无限循环 |
| PostCSS | 8.5.15 | 8.5.32 | 修复 sourceMappingURL 路径访问相关问题 |
| source-map-js | 1.2.1 | 1.2.2 | 修复构造 source map 导致的拒绝服务 |
| MySqlConnector | 2.2.5 | 2.6.1 | 修复特定零配置 TLS 连接条件下，在证书验证前发送密码的问题 |

Core 项目通过 SqlSugar 的 MySQL 提供程序间接引入 MySqlConnector，因此在 Core 显式引用安全修复版；脚本项目同步升级，保证单独使用任一项目以及加载协议插件时都不会回退到旧版本。SQL Server 的驱动、配置与数据库结构没有调整。

同步更新了 npm 和 NuGet 锁文件，保留 NuGet 全量安全审计。没有通过忽略安全公告、关闭审计或强制不兼容的依赖覆盖来隐藏问题。
